# 智能云 AI 商城

电商在线销售系统课程演示。原生 HTML、CSS 与 JavaScript 实现，适配电脑与手机。

## 演示账号

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 用户 | demo | Demo123456 |
| 管理员 | admin | Admin123456 |

以上账号仅供本商城静态演示使用。

## 功能

- 商品分类、关键词搜索、价格与销量排序、商品详情与收藏。
- 购物车、数量调整、库存校验、优惠券、运费与合计计算。
- 本地账号注册和演示登录、模拟下单、支付、发货、收货与取消订单。
- 管理员商品价格和库存编辑、销售统计与订单 CSV 导出。
- 根据商城商品与关键词匹配的选购助手。

## 体验流程

1. 使用用户账号登录，挑选商品、加入购物车并提交演示订单。
2. 在“我的订单”点击“模拟支付”。
3. 退出后使用管理员账号登录，在“管理后台”模拟发货。
4. 改用用户账号登录，在“我的订单”确认收货。

请在同一浏览器切换账号完成演示。收货表单可使用默认虚拟信息。

## 部署

仓库根目录即静态网站目录。GitHub Pages 可选择从 `main` 分支的 `/ (root)` 部署，无需安装依赖或构建。

## 实现说明

本项目是静态课程演示。数据保存在当前浏览器的 localStorage，不同浏览器和设备之间不共享。演示登录用于展示流程，不具备服务器端权限保护。

初始商品、销量为演示数据，支付、物流和选购推荐为模拟功能，未连接真实支付、数据库或大模型服务。商品插图为原创 SVG。
